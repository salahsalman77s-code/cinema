# Safafi Cinema

واجهة ويب للأفلام والمسلسلات والأنمي متصلة بخدمات FrameXTV.

## التشغيل

الموقع مصمم للنشر كملفات ثابتة على GitHub Pages، دون خطوة بناء.

لتفعيل النشر: Settings → Pages → Deploy from a branch → main → /(root) → Save.

الرابط بعد تفعيل Pages: https://salahsalman77s-code.github.io/cinema/

لتجربة Windows محليًا، شغّل Start-Safafi-Web.cmd واترك نافذته مفتوحة.

## ملاحظات

المشروع يعتمد على خدمات خارجية لتوفير البيانات والتشغيل. لا يحتوي المستودع على ملفات أفلام.
